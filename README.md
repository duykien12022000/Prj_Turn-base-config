# Prj_Turn-base-config

Published game configuration catalog for Prj_Turn-base, served by GitHub Pages at
`https://duykien12022000.github.io/Prj_Turn-base-config/manifest.json`.

- `manifest.json` names the current revision, its file and SHA-256.
- `catalog-<revision>.json` files are immutable; older revisions stay for devices that are mid-update.

Do not edit files here by hand. Build them in the game project (`BallvsBall/Config/Build Catalog`), run the
tests, then use `BallvsBall/Config/Copy Catalog To Pages Folder` and commit + push this repository.
